**Twin Tides** — a spot-the-difference hunt in three hand-drawn worlds. Two pictures sit side by side and look the same; they are not. Find all 7 differences in Harbour Dawn, Lantern Market and Foxglove Garden before the tide (the clock) runs out. Every scene is drawn in canvas paths by the game itself — no image files, no borrowed art. Found differences get a gold ring on both pictures, wrong clicks cost time and a strike, hints ring a hiding difference for a few seconds, and finishing all three scenes wins the hunt.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network request — `game/` is plain static files.
